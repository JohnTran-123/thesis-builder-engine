# Thesis Builder Engine — AI Dispatcher

This file is the AI entry point. It indexes the skills, rules, protocols, and agents the AI loads on demand. Keep this file under 200 lines — substance lives in scoped files, not here.

**Project:** Thesis Builder Engine — end-to-end thesis-writing engine for Claude Code.
**Audience:** Undergrad / grad students writing thesis-style documents.
**License:** MIT.

---

## WORKFLOW

```
   ALIGN ─→ PLAN ─→ EXECUTE ─→ CONTENT-REVIEW ─→ AI-REVIEW ─→ PRESUBMIT
     ▲                              │                │              │
     └────────────────── REVISE ────┴────────────────┴──────────────┘
```

Start point: invoke `/align`. The 12-question questionnaire at `QUESTIONNAIRE.md` anchors all downstream work.

## DECISION TREE — WHEN TO LOAD WHAT

| **USER SIGNAL** | **AI ACTION** |
| :-------------- | :------------ |
| Empty workspace, "help me start", "new project" | Suggest `/align`. Load `skills/align/SKILL.md` |
| Alignment complete, "let's plan" | Load `skills/plan/SKILL.md` |
| "Draft chapter N", "write section X" | Load `skills/execute/SKILL.md` |
| "Review this content", "check structure" | Load `skills/content-review/SKILL.md` |
| "Check for AI detection", "will this get flagged" | Load `skills/ai-review/SKILL.md` + `protocols/PROTOCOL_ANTI_AI.md` |
| "Ready to submit", "final checks" | Load `skills/presubmit/SKILL.md` |
| "Find sources on X", literature work | Spawn `agents/research-assistant.md` |
| AI considers rewriting AI-flagged text | HARD STOP. Load `rules/meta-rule-zero.md`. Defer to user. |
| "Advisor sent comments — integrate them" | Re-run `/align` Sub-step 2 walkthrough on changed items if scope shifts; otherwise edit affected `workspace/drafts/<section>.md` and re-run `/content-review` on that section. |
| "I want to revise my outline mid-execute" | Run `/plan` again — it will overwrite `workspace/plan/plan.md`. Existing drafts are NOT discarded; map them to the new outline manually. |
| "GPTZero flagged my submitted draft — fix" | Re-run `/ai-review` on affected sections. Author rewrites per `rules/meta-rule-zero.md`. Then re-run external check + `/presubmit`. |

## APPROVAL PHRASES

| **WHEN** | **REPLY** |
| :------- | :-------- |
| After skill output / draft section | **"Approved"** |
| At phase boundary (alignment→plan, plan→execute, etc.) | **"Proceed"** or **"Re-plan"** |
| At commit / docx export | **"Yes"** |

Hard-stop discipline mandatory. Never proceed silently. See `rules/approval-discipline.md`.

---

## CRITICAL PRINCIPLES (one-line summaries — deep refs linked)

1. **AI never rewrites AI text.** If AI-detection flags content, the AUTHOR rewrites. → `rules/meta-rule-zero.md`
2. **Alignment first.** No drafting until `workspace/alignment/alignment.md` exists. → `rules/approval-discipline.md`
3. **One section at a time.** Hard-stop after each. Wait for "Approved". → `rules/approval-discipline.md`
4. **Honest scope.** Disclose limitations and unvalidated claims. → `rules/honest-scope.md`
5. **No fabricated citations.** Every cite verifiable. → `rules/no-fabricated-citations.md`

3. Read `workspace/_session.md` to recover state.
4. Skills, protocols, agents load on demand per the decision tree above.

## FOR NEW USERS

If `workspace/_session.md` shows no prior activity AND `workspace/alignment/` is empty: the user is new. Greet briefly, point them to `README.md` and `QUESTIONNAIRE.md`, then offer `/align`.
